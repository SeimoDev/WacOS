# WacOS website

One quiet screen, static, no dependencies (`index.html`, `style.css`, `app.js`). Open `index.html` directly or run
`python -m http.server 8080`.

- Slogan: 站中间，串两边 / "Stay in the middle, roam both sides." Chinese is the markup default; English lives in `app.js`.
- Light and dark follow the system setting.
- The download link goes to the latest GitHub release.
