# WacOS — 在 Windows 11 上还原 macOS 的多桌面（Spaces）、调度中心（Mission Control）与台前调度（Stage Manager）

WacOS 把 macOS 的两大窗口管理功能原样搬到 Windows 11，包括操作效果、触控板手势、键盘快捷键和系统设置项：

* **Spaces / 调度中心** — 多桌面、顶部空间栏、窗口在桌面之间拖放、Ctrl+←/→ 切换、三指/四指滑动、触发角、
  应用程序窗口（App Exposé）、显示桌面、每个桌面独立壁纸、"将应用分配到桌面"、按最近使用自动排列、全屏应用独占一个空间。
* **台前调度** — 当前应用在舞台中央，最近使用的应用以缩略图排在左侧；支持编组（Shift 点按 / 拖拽）、
  点按壁纸显示桌面、侧栏自动隐藏、"同时显示 / 逐个显示"、桌面项目显示开关、每个桌面和每台显示器独立状态。

macOS 完整特性清单以及每一项在 Windows 上的实现方式见
[`docs/macOS-Feature-Inventory.md`](docs/macOS-Feature-Inventory.md)（英文）。

## 1. 系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 11 24H2 或 25H2（内部版本 26100 及以上）。虚拟桌面的内部 COM 接口与系统版本强绑定，旧版本无法使用。 |
| 运行时 / 编译 | .NET 8 SDK（`dotnet --list-sdks` 可查看） |
| 手势 | 精确式触控板（Precision Touchpad，现代笔记本基本都是） |
| 权限 | 普通用户即可。设置 → General →"Run as administrator"可开启管理员模式，用来完整管理以管理员身份运行的程序窗口 |

## 2. 编译与运行

```powershell
cd src\WacOS
dotnet build -c Release
.\bin\Release\net8.0-windows10.0.19041.0\WacOS.exe
```

命令行参数：

| 参数 | 作用 |
|---|---|
| `--selftest` | 不启动界面，仅打印检测到的桌面、显示器和窗口（含截图能力），用于检查新系统版本是否兼容 |
| `--verbose` | 输出调试日志到 `%AppData%\WacOS\wacos.log` |
| `--stage` | 启动时强制开启台前调度（忽略已保存的设置） |
| `--lang <代码>` | 本次运行临时指定界面语言：`en`、`zh-Hans`、`zh-Hant`、`ja` |
| `--settings` | 启动后直接打开设置窗口 |
| `--quit` | 让正在运行的实例优雅退出（恢复所有被收纳的窗口、卸载钩子、恢复桌面图标） |

WacOS 常驻系统托盘：**左键**托盘图标 = 调度中心，**右键** = 菜单（台前调度开关、桌面列表、
新建/删除/重命名桌面、为当前桌面选壁纸、"将 xx 分配到…"、设置、日志、退出）。首次运行会自动打开设置窗口。

## 界面语言

托盘菜单、设置窗口、提示和对话框支持 English、简体中文、繁體中文、日本語。默认跟随系统语言，
可在 设置 → 通用 → 语言 中切换，立即生效。翻译集中在 `src/WacOS/Localization/Strings.cs` 一张表里，
以英文原文为键；新增语言只需在表里加一列并在 `L.cs` 登记。

## 3. 默认快捷键与手势（与 macOS 一致）

| 操作 | 键盘 | 触控板 |
|---|---|---|
| 调度中心 | Ctrl+↑ 或 F3 | 三指/四指向上滑 |
| 应用程序窗口（App Exposé） | Ctrl+↓ | 三指/四指向下滑 |
| 显示桌面 | F11 | 拇指与三指张开 |
| 向左 / 向右移动一个空间 | Ctrl+← / Ctrl+→ | 三指/四指左右滑 |
| 切换到桌面 N | Ctrl+1 … Ctrl+9，Ctrl+0 = 桌面 10（默认关闭） | – |
| 打开 / 关闭台前调度 | 无默认（可自定义） | – |
| 循环切换当前应用的窗口（macOS ⌘`） | Alt+` | – |
| 启动台（可选，映射为开始菜单） | – | 拇指与三指捏合 |

调度中心内部：**Esc** 退出 · **空格** 快速查看（放大悬停的窗口）· 按住 **Alt** 显示所有桌面的 ✕ ·
**Alt+点按** 空间缩略图 = 切换但不退出 · 点按空白区域退出 · 点按窗口 = 切到该窗口并退出。

> **两点提醒**
> 1. Ctrl+←/→ 在 Windows 编辑器里是"按词移动光标"，F11 在浏览器里是全屏。WacOS 按 macOS 默认值全局接管这些键；
>    设置 → 键盘快捷键 页面有一键改为 Win+Ctrl+←/→ 的开关，所有快捷键都可以改。
> 2. Windows 自带的三指/四指轻扫会和 WacOS 的手势同时触发。WacOS 运行期间会自动把它们设为“无”，退出时恢复你原来的设置
>    （设置 → 触控板 里可以关掉这个行为）。如果开启后系统手势仍然有反应，注销并重新登录一次即可。

## 4. 功能说明

### 4.1 Spaces（多桌面）

* 使用 Windows 自带虚拟桌面作为空间，最多 16 个（与 macOS 相同）；未命名的桌面显示为"Desktop N"。
* 切换不循环：在最后一个桌面按 Ctrl+→ 不会跳回第一个。
* **拖窗口到屏幕左/右边缘并停留约 1 秒**，窗口连同你一起移到相邻空间（单显示器或最外侧显示器）。
* **拖着窗口时按 Ctrl+←/→**，窗口跟着你一起切换。
* **拖窗口到屏幕顶部**进入调度中心，松手时落到哪个空间缩略图就移到哪个空间，落到"+"上则新建空间并放入。
* 每个桌面可单独设置壁纸（托盘菜单 → Spaces → 为当前桌面选择壁纸）。
* **将应用分配到桌面**：托盘菜单 →"将 xx 分配到…"→ 所有桌面 / 此桌面 / 无。"所有桌面"等价于 Windows 的
  "在所有桌面上显示此窗口"；"此桌面"会把该应用新打开的窗口自动移到指定桌面。设置 → Apps on Desktops 可查看和管理。
* **按最近使用自动排列空间**：与 macOS 一致，只有因为激活了另一个空间里的应用而发生切换时，才把那个空间挪到当前空间旁边；用快捷键、手势或调度中心自己切换空间不会改变顺序。
* **全屏应用独占空间**：某个窗口进入全屏（无边框且铺满显示器）时自动新建一个以应用命名的空间，放在原空间右侧并移入；退出全屏后窗口回到原空间并保持为活动窗口，临时空间随即删除。可在设置中关闭。注意默认的“显示桌面”快捷键是 F11，会拦截浏览器的 F11 全屏，需要时请在快捷键页改掉。
* 删除空间时，其窗口移到左侧相邻空间（第一个空间被删时移到第二个）。

### 4.2 调度中心（Mission Control）

* 每台显示器各有一个覆盖层，背景为当前壁纸虚化。
* 顶部**空间栏**默认折叠只显示名称，鼠标移到顶部或拖动窗口时展开为缩略图；缩略图中会画出该空间里的窗口。
* 悬停空间缩略图出现 ✕（只有一个空间时不显示）；按住 Alt 全部显示。拖动缩略图可调整顺序。右端"+"新建空间。
* 当前空间的窗口按其真实位置关系排布成若干行，不放大只缩小；开启"按应用程序分组窗口"后同一应用的窗口叠放并显示应用图标。
* 悬停窗口显示应用图标 + 标题；把窗口缩略图拖到某个空间或"+"上即可移动。
* 窗口预览是 DWM 实时缩略图（由 GPU 合成），内容是活的；打开时窗口从真实位置飞到排布位置，关闭时飞回，任务栏保持可见。
* **应用程序窗口（App Exposé）**：只显示前台应用的窗口，最小化的窗口以小图排在底部。

### 4.3 显示桌面

窗口（实时画面）向最近的屏幕外侧边缘滑出，再按一次滑回，层叠顺序保持不变；点击任意窗口也会结束"显示桌面"状态。台前调度开启时，该命令改为把舞台上的窗口收进侧栏 / 再次放回。

### 4.4 触发角

四个角分别可设为：调度中心、应用程序窗口、桌面、通知中心、启动台（开始菜单）、快速备忘录、锁定屏幕、
使显示器进入睡眠、无。可要求按住 Ctrl/Shift/Alt/Win 才触发。指针一碰到角落即触发，离开后重新武装。

### 4.5 台前调度（Stage Manager）

* 开启方式：托盘菜单、设置、或自定义快捷键（macOS 同样没有默认键）。
* 开启后，前台应用的窗口留在舞台中央，其他应用按最近使用顺序收纳到左侧侧栏（最多 6 个，取决于屏幕高度），
  缩略图左下角带应用图标；同一组多个窗口叠放显示。
* 侧栏缩略图带透视，平时绕左边缘向屏幕内侧（舞台方向）转约 48 度，应用图标不跟着倾斜、正面压在左下角，与原版一致；把窗口拖向侧栏时，缩略图带弹簧动画转正，变成平直的放置目标，松手或移开后再转回倾斜。
* 窗口收进侧栏的交接：飞行中的窗口画面是平的（系统合成的实时缩略图无法做透视），所以在它即将到位时，侧栏里的缩略图以平直姿态淡入接手，随后带弹簧转到倾斜角度；应用图标稍后从小到大弹出。
* 一组里有多个窗口时按原版方式折叠：最前面的窗口在右，后面的窗口依次缩小、从左侧露出边缘（最多显示 4 个）。
* 拖窗口到侧栏时的提示分两种：该应用在侧栏里还没有格子，就在顶部预留一个空位；已经有格子（松手后会并入），则不留空位，而是把那一格放大高亮。
* **点按**缩略图：该组来到舞台，原来舞台上的组回到侧栏（带飞入飞出动画，系统自带的最小化动画在开启期间被关闭）。
* **Shift+点按** 或 **把缩略图拖到舞台上**：加入当前组（编组）。
* **把舞台上的窗口拖到左侧侧栏**：该窗口离开舞台、收进侧栏。指针进入侧栏范围后，侧栏滑出并在顶部让出一个空位提示，松手后窗口飞入；舞台上只有一个窗口时同样有效。再次取回时窗口回到拖动前的位置。
  拖动是根据"窗口位置变化 + 指针位置"识别的，因此对所有程序通用：自绘标题栏的应用（Electron 等）、以管理员身份运行的程序（任务管理器、Clash、游戏平台等）都支持。
  多窗口应用（主窗口带附属面板的那类）：拖动时跟着一起移动的同进程窗口，或与被拖窗口有从属关系的窗口，会作为一个整体一起收进侧栏，取出时也一起回来并保持相对位置。
* **从侧栏把缩略图往右拖出**：窗口的实时画面跟随指针，离侧栏越远越大；在舞台上松手，它就落在指针处并加入当前组；拖回侧栏范围内松手则弹回原位。
* **屏蔽系统边缘贴靠**：台前调度开启期间，Windows 的"拖到屏幕边缘分屏"会被临时关闭（左边缘属于侧栏），关闭台前调度或退出时自动恢复；可在设置里取消（"Turn off Windows edge snapping while Stage Manager is on"）。
* 新打开的应用会占据舞台，原组退到侧栏；同一应用的新窗口加入舞台上的组（"同时显示"模式）。
* Alt+Tab、任务栏切换应用同样触发组切换：当前组收进侧栏与目标窗口从侧栏飞出同时进行（目标窗口在动画开始前保持隐藏，不会先在原位闪现）。
* **最小化**（相当于 ⌘M）：窗口飞入侧栏而不是任务栏。
* **点按壁纸**：舞台上的所有窗口收进侧栏，显示桌面；再点缩略图即可回来。
  设置里可选"总是"（不开台前调度也生效）或"仅在台前调度中"。
* 舞台上的窗口会自动向右推开一点，避免压住侧栏。窗口挡住侧栏时（包括拖动过程中），侧栏主动向左滑出屏幕避让；鼠标移到屏幕左边缘，或窗口不再遮挡时，侧栏从左侧滑回。
* 收纳只看鼠标指针：拖着窗口时，只有指针进入侧栏区域，侧栏才会滑出来并转正成放置目标，在那里松手才收纳；窗口只是靠近或盖住侧栏不会被收起。
  关闭"显示最近使用的应用"后侧栏始终隐藏，只在左边缘悬停时出现。
* **拖放弹簧加载**：拖着文件/内容在某个缩略图上停留约 0.7 秒，该组会弹到舞台，方便放入。
* 每个空间、每台显示器各自维护一套台前调度状态；全屏窗口不纳入。
* 桌面图标：设置 → "显示项目：在桌面上 / 在台前调度中"，分别控制普通模式和台前调度模式下桌面图标是否显示。

## 6. 动效实现

所有过渡移动的都是窗口的**实时画面**而不是截图：WacOS 为真实窗口注册 DWM 缩略图，由桌面合成器在 GPU 上绘制；
一个跟随 `DwmFlush`（每合成一帧返回一次）的独立线程按临界阻尼弹簧曲线逐帧更新位置，因此动画与显示器刷新率同步
（高刷屏上即 120/144/165fps），并且不受界面线程卡顿影响。调度中心窗口本身是不透明、预先渲染好并保持 DWM 隐藏（cloak）的，
打开时零延迟，第一帧就是桌面的精确画面，所以窗口看起来是直接从原位飞出去的。
加 `--verbose` 运行可在日志里看到每段动画的帧数与帧间隔统计。

**无闪烁**：离开屏幕的窗口（收进侧栏、显示桌面）不是被最小化，而是由系统外壳"隐藏（cloak）"，与 Windows 隐藏其他虚拟桌面窗口
用的是同一机制。被隐藏的窗口继续渲染、缩略图保持实时，重新出现时应用无需重绘，所以动画结束时不会闪一下。
所有被隐藏的窗口都记录在 `%AppData%\WacOS\hidden-windows.txt`，退出或下次启动时自动恢复，异常退出也不会丢窗口；
在任务栏或 Alt+Tab 里激活被隐藏的窗口，系统也会立即让它显现。

**曲线**：调度中心进入用长尾减速的贝塞尔曲线（expo-out），退出用快起缓落的曲线，并按移动距离做轻微错峰；
台前调度用带轻微回弹的真实阻尼弹簧，多窗口依次出发；显示桌面滑出时加速离场，滑回时用弹簧落位；侧栏项目让位同样走弹簧。

## 管理员模式（可选）

普通权限下，以管理员身份运行的程序（任务管理器、Clash、游戏平台等）的窗口可以被收进侧栏和取出，缩略图也正常，
但 Windows 不允许普通进程移动它们，所以取出时只能回到原来的位置，也无法把它们从侧栏旁推开。

在 设置 → General 打开"Run as administrator"后，WacOS 会以管理员身份重新启动，这些窗口就和普通窗口完全一样了。
开启后：

* 每次启动时 WacOS 会自行提权；是否弹出确认框取决于系统的 UAC 设置。
* 勾选"登录时启动"时，改用一个"最高权限"的计划任务（名为 `WacOS (administrator)`）来启动，登录时不会弹确认框。
* 关闭该选项后从下次启动起恢复普通权限。
* 命令行加 `--elevate` 可临时以管理员模式启动一次，不改设置。

## 7. 与 macOS 的差异 / 已知限制

* Windows 的虚拟桌面天然横跨所有显示器，因此"显示器具有单独的空间"只影响调度中心和台前调度按显示器分别显示，
  不能做到每台显示器独立切换桌面。
* **以管理员身份运行的程序**：普通权限下能收纳、不能移动；需要完整控制请开启上面的管理员模式。
* macOS 的"隐藏应用"（⌘H）在 Windows 没有对应概念；从调度中心拖窗口到全屏空间形成分屏（Split View）不在本项目范围内。
* "全屏应用独占空间"是通过把全屏窗口移到新建的虚拟桌面来模拟的。
* 少数窗口（例如某些硬件加速/受保护内容）无法截图，缩略图会退化为应用图标。

## 8. 排错

| 现象 | 处理 |
|---|---|
| 启动提示无法连接虚拟桌面服务 | 系统版本低于 26100，或微软在更新中又改了内部接口。运行 `WacOS.exe --selftest` 查看详细错误 |
| 快捷键无反应 | 检查是否有其他软件先截获了同一组合键；设置 → 键盘快捷键 里可换键 |
| 手势无反应 | 设置 → 触控板 页面会显示是否收到精确式触控板数据；用三根手指碰一下触控板再看。外接普通鼠标/非精确式触控板不支持 |
| 重新编译时报 MSB3021 文件被占用 | 先运行 `WacOS.exe --quit` 退出旧实例 |
| 退出后有窗口不见了 | 重新启动 WacOS 会自动恢复；或在任务栏点一下该窗口 |
| 日志位置 | `%AppData%\WacOS\wacos.log`（托盘菜单 → Open Log） |

## 9. 项目结构

```

  Native/            Win32 / DWM / HID 的 P/Invoke，WinEvent 钩子，低级键鼠钩子（独立线程）

  Features/
    Spaces/          快捷键/手势切换、拖到边缘、应用分配、自动排列、全屏独占空间

    StageManager/    StageManagerService、StripWindow（侧栏）
    Anim / ThumbAnimator / OverlayWindow   动画引擎（弹簧曲线、跟随合成器节拍的缩略图动画）
    ShowDesktopService、HotCornerService
  Settings/          设置模型（JSON）+ 设置窗口
  Tray/              托盘图标与菜单
docs/macOS-Feature-Inventory.md   macOS 特性清单与实现对照
```
